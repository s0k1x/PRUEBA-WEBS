s0k1x-skill · v1.1.0

Un kit de skills.
Una sola skill al mando.

35 skills para Claude Code que funcionan juntas o por separado: diseño web, componentes con oficio, textos naturales, animaciones, ahorro de tokens e ingeniería. Tú pides la tarea; s0k1x-skill decide qué usar y en qué orden.

Instalar

En Claude Code, añade el repositorio y luego instala el plugin:

/plugin marketplace add s0k1x/prueba-webs
/plugin install s0k1x-skill@s0k1x-skill

En Claude Code 2.1.275 o posterior también puedes hacerlo en un paso:

/plugin install s0k1x-skill --marketplace s0k1x/prueba-webs

¿Solo quieres una skill? Cada una se instala por separado, con lo que necesita para funcionar:

/plugin install s0k1x-componentes@s0k1x-skill

Cambia s0k1x-componentes por cualquier skill de la lista. Instala el kit completo o skills sueltas, no las dos cosas, para no tener la misma skill repetida. La coordinadora y los mods vienen solo con el kit.

Descargar

git clone https://github.com/s0k1x/prueba-webs.git

O descarga el archivo ZIP. Para probarlo sin instalarlo, desde la carpeta descargada:

claude --plugin-dir .

Cómo funciona

Pide la tarea con normalidad, por ejemplo "hazme una web para una peluquería". Para una web nueva, el kit sigue este orden:

  1. s0k1x-estilo: elige el estilo, las fotos y las referencias, y hace la primera versión.
  2. s0k1x-componentes: construye cada pieza con oficio: estados, luz, material y recursos propios.
  3. s0k1x-humano: reescribe los textos para que suenen naturales.
  4. s0k1x-movimiento: añade solo las animaciones con sentido.
  5. s0k1x-pulido: revisa jerarquía, accesibilidad y móvil.
  6. s0k1x-verificar: comprueba que cumple lo pedido y para.

Cada decisión tiene una sola skill responsable. La accesibilidad, la seguridad y lo que pidas tú ganan siempre.

Antes de usarlo

Algunas skills te piden permiso porque envían datos fuera o cambian tu configuración: las de la nube externa (s0k1x-breve-configurar y similares), s0k1x-breve-comprimir y los arreglos de s0k1x-tokens.

Requisitos: Claude Code. Algunas skills usan Python 3, y s0k1x-pulido descarga su motor la primera vez.
