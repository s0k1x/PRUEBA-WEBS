Instalar el kit

Instalación en Claude Code y Codex

Dos comandos para el kit completo. Las skills son las mismas en las dos herramientas.

Añade el repositorio como marketplace e instala el plugin. Trae las 35 skills, los 3 subagentes y los mods.

Ver las 35 skills

Codex usa las skills desde .agents/skills. Con -g quedan para todos tus proyectos.

Ver qué cambia en Codex

Cada skill es un plugin propio y trae lo que necesita. Cambia s0k1x-componentes por la que quieras.

Pides la web con normalidad. s0k1x-skill encadena seis skills y cada una se ocupa de una sola decisión.

Preguntas frecuentes

¿Instalo el kit o skills sueltas?

Una de las dos cosas. Si instalas ambas, la misma skill aparece dos veces con nombres distintos.

¿Qué cambia en Codex?

Las skills y los flujos son los mismos. Los subagentes y los mods solo existen en Claude Code.

¿Puedo modificar el código?

No. La licencia permite instalar y usar el kit tal cual. Las skills de otros autores conservan su licencia.

¿Envía datos fuera?

Solo s0k1x-breve-comprimir y las skills de la nube externa, y siempre piden permiso antes.
