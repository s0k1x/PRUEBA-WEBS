Preguntas

Lo que suele preguntarse

¿Instalo el kit o skills sueltas?

Una de las dos. Si instalas ambas, la misma skill aparece repetida.

¿Qué cambia en Codex?

Las skills y los flujos son iguales. Los subagentes y los mods son solo de Claude Code.

¿Qué necesito para usarlo?

Claude Code o Codex. Algunas skills necesitan Python 3.

¿Puedo modificar el código?

No. Puedes instalarlo y usarlo tal cual. Las skills de otros autores conservan su licencia.

¿Envía datos fuera?

Solo s0k1x-breve-comprimir y las skills de la nube externa, y piden permiso antes.
